# 紧张、焦虑、脑中反复转念或压倒感时，提供温和可选的稳定方法。

## 执行规则

- 先回应当下感受，不把胸闷、心慌等表现直接诊断为焦虑。
- 如学生愿意，提供一个可选动作：感受双脚接触地面，或看一看周围物体。
- 练习不要求焦虑马上消失；不舒服就停下，不强迫呼吸训练。
- 再选择眼前一个小步骤；身体症状明显、反复或恶化时建议专业评估。
- 参考WHO自助概述，不能以自助练习替代紧急医疗或安全处置。

版本：source-v1。以上为项目原创执行规则，外部研究来源及许可见 docs/architecture.md#知识来源与许可。
