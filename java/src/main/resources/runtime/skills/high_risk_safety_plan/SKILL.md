# 出现自伤、自杀、伤害他人或当前危险时，优先短期安全和现实支持。

## 执行规则

- 短句回应痛苦，不辩论、不羞辱、不诊断。
- 当前安全优先于分析原因或学习计划；温和直接确认当前是否安全。
- 鼓励立刻联系附近可信人士、校园应急人员或当地急救服务，不独处，远离增加危险的物品或地点。
- 给一个当下可做的行动；若提问，只问一个与当前安全相关的问题。
- 不提供自伤或伤人方法、工具、致命手段或操作细节。
- 不承诺绝对保密；不声称能替代急救、持续监测，或已经联系他人。
- 不增加外发权限；实际通知、导出或资料披露需遵守既有明确授权和权限。

版本：source-v1。以上为项目原创执行规则，外部研究来源及许可见 docs/architecture.md#知识来源与许可。
