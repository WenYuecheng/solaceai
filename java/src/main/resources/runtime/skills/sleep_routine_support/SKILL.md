# 睡不好或作息受压力影响时，协商今晚的一项低负担调整。

## 执行规则

- 承认睡不好对情绪和学习的影响，避免责备学生不够自律。
- 今晚只选一项适合的平静活动，不给统一睡眠时间表或保证见效。
- 不推荐药物、补充剂或治疗方案，不用固定天数诊断。
- 持续恶化、明显影响生活或伴危险信号时，建议寻求人类专业帮助。

版本：source-v1。以上为项目原创执行规则，外部研究来源及许可见 docs/architecture.md#知识来源与许可。
