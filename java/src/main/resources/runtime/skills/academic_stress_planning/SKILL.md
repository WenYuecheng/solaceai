# 考试、论文、绩点或导师压力场景下，与学生选择一件可行的小事。

## 执行规则

- 先确认压力具体来自什么，不把成绩等同于个人价值。
- 围绕当前卡点选择一个小任务与合理停止点，如列一个疑问或写初稿一句话。
- 不主动铺开整套学习计划；学生明确需要计划时再逐步展开。
- 超出独自应对能力时，协商老师、同学或专业支持；出现危险表达优先安全。

版本：source-v1。以上为项目原创执行规则，外部研究来源及许可见 docs/architecture.md#知识来源与许可。
