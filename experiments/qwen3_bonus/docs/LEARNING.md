# 算法、论文与面试讲解

## 这项实验真正研究什么

在已有安全、检索和工具系统里，用一个小模型承担云端故障时的两种任务：四分类和简短支持回复。对照问题是“相同 Qwen3 基座、相同上下文下，少量 LoRA 更新是否改善分类或人工偏好”。工程接入、训练损失下降与心理支持效果是三个不同的证据。

分类有明确标签，先用监督学习更直接。回答有多种合理表达，适合尝试偏好奖励的强化学习。首轮不对分类做 GRPO，把有限生成预算用于回答。无须给每项功能都加强化学习。

## LoRA、QLoRA 与两个适配器

线性层原权重为 W，LoRA 把实际计算写成 `W x + (alpha/r) B A x`。W 冻结，只学习低秩 A、B；本实验 r=8、alpha=16，只改注意力的 q_proj、v_proj。两个适配器各自独立训练，分别叠加于同一个原基座；分类适配器不会成为回答训练的起点。

QLoRA 还把冻结 W 以 4-bit 保存，计算时反量化；可训练 LoRA 本身仍采用较高精度。分类使用 NF4、双量化和 BF16 计算。回答按已核对的 [verl 0.5 LoRA 官方路线](https://verl.readthedocs.io/en/v0.5.x/advance/ppo_lora.html)使用 BF16 基座 + PEFT LoRA + FSDP + vLLM rollout，不能称为 QLoRA。本地 MLX 4-bit 是另一阶段的部署量化，与训练时的 NF4 不是同一种文件格式。

分类最大 256 tokens，仅标签和模板结束 token 计算交叉熵，提示 token 的 labels 为 -100。这样学习的是给定输入后的标签，而不是抄写提示。过长提示从左截断并保留答案，四类各 300 条。训练最多一轮不代表收敛。

## 一步 GRPO 是怎样进行的

1. 从冻结的 128 个训练上下文取一个 x，其中最后一条是用户发言，不含未来参考答案。
2. 当前策略对同一个 x 采样 G=2 个回答 y1、y2；温度 0.8，最多 256 tokens。
3. 冻结奖励模型分别打分，加上有限违规筛查和重复惩罚，得到 r1、r2。
4. 以组内相对好坏构造优势：`Ai = (ri - mean(r)) / (std(r) + eps)`。verl 的具体 std 约定由固定的 0.5.0 源码实现，代码不自行改写。
5. 用 PPO 风格 clipped surrogate 更新 LoRA，另加相对于冻结基座的 KL 惩罚，防止策略离开原能力太远。

目标的示意形式：`mean_i mean_t min(ratio_it * Ai, clip(ratio_it,1-eps,1+eps) * Ai) - beta * KL`，其中 ratio 是新策略与采样时旧策略的 token 概率比，beta=0.02。冻结参考策略用于 KL，旧策略用于 ratio，两者角色不同。代码显式选择 vanilla policy loss、seq-mean-token-mean 聚合、组内标准差归一化和 low_var_kl，不依赖不断变化的框架默认值。

GRPO 不训练 critic/value 网络，省去价值模型；参考基座在 verl LoRA 实现中通过同一模型禁用适配器计算。训练 actor 与 vLLM rollout 仍各有模型状态/缓存， **共享参考基座并不意味着整张卡只有一份 4B 权重** 。24 GB 是否够用，以实际 pilot 峰值显存为准；CPU offload 和分层同步可以降低峰值，却会降低吞吐。

G=2 是预算折中：只知道两个回答谁更好，标准化后优势幅度很大程度被归一，原始分差大小不再充分体现。若二者奖励相同，本组几乎没有学习信号；连续 8 步全组无差异就保存停止。小 batch、低 rank、32 步都限制质量，不应承诺提升。verl 的一个 batch 含 1 个提示，展开为 2 个回答；按其官方 actor microbatch 机制更新，不能把它简单等同于原 TRL 配置中的梯度累积 2。

## 本轮奖励准确地实现了什么

`reward = sigmoid(Skywork_score) - 0.2 * repetition_ratio`。重复率是在去空白后的字符 4-gram 中，重复出现的部分占全部 4-gram 的比例。空回答、明显无效协议文本，以及规则能确定的少量伤害指导、肯定式诊断或处方输出，奖励直接为 -1。

模型是 [Skywork-Reward-V2-Qwen3-0.6B](https://huggingface.co/Skywork/Skywork-Reward-V2-Qwen3-0.6B)，使用官方 sequence-classification/聊天模板，冻结、CPU 运行。它提供通用偏好信号，没有证据说明它已经是可靠的中文心理学奖励模型。sigmoid 可能压缩差异；因此既记录训练奖励，也记录组内差异、KL、长度、截断及输出。最终评测独立于训练奖励。

20 对中文 sanity pairs 只取训练上下文：PsyDT 参考回答对比人工编写的弱回答，顺序随机，偏好留空。阅读上下文后由人填写 expected、reviewed、reviewer；至少 15/20 排序一致才能租卡。这个测试只发现明显奖励错位，不是心理学有效性验证。不能用模型自己填“人工审核”字段，也不能用 40 条冻结评测题反复调奖励。

## 如何评估、如何继续改进

分类报告四类 Macro-F1、混淆矩阵、高风险漏判数和实际延迟。400 条原合成回归用于对照，不作真实人群泛化宣称。回答以同一 40 条上下文的基座与适配器输出做匿名随机顺序盲评，五个维度 1–5 分，同时记录整体胜负、严重安全退化及理由。训练奖励不能充当裁判。

首轮只有“可复现实验”的结论。若真正出现提升，再报告真实胜/负/平、分维度结果、KL/奖励曲线。下一轮先分析失败样本及奖励差异，再考虑更充分的回答 SFT、更大的 G、rank 或训练步数；改动一次只变一个因素并重新冻结独立评测。多轮模拟用户贴近 RLVER，但同时增加模拟偏差、rollout 长度和成本，应作为后续研究而非本轮偷偷加入。
