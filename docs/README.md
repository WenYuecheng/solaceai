## 代码与工程组织规范

- 系统核心业务微内核集中于 `packages/core/app/`。
- 本次仓库包含线下适配器 `apps/offline/` 与独立模型服务 `apps/rag_worker/`。
- 现代化前端交互界面位于 `frontend/`。
- 完整项目既有回归记录为后端 592 passed、4 skipped，前端单元与组件测试 81 passed；浏览器测试结果见评测报告。完整测试目录未包含在本次精简上传中。
- `evaluation/` 保留原有说明；评测执行代码、真值数据与运行结果未全部包含在本次上传中。
- 强化学习与双 LoRA 代码和说明位于 `experiments/qwen3_bonus/`；模型及训练产物不随源码上传。
- 容器编排定义与模块化依赖位于 `deploy/` 与各应用的独立 `compose.yml`。
- 技能、知识语料、分词器数据、图片字体、运行数据与模型权重均按既定上传范围省略，部署时单独准备。
