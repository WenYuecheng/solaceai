## 代码与工程组织规范

- 系统核心业务微内核集中于 `packages/core/app/`。
- 多端独立应用适配器位于 `apps/online/`、`apps/offline/` 与 `apps/rag_worker/`。
- 现代化前端交互界面位于 `frontend/`。
- 全量自动化测试用例集中于 `tests/`（590+ 项自动化回归测试持续 100% 绿灯通过）。
- 离线评测套件与真值数据集位于 `evaluation/`。
- 强化学习与双 LoRA 训练代码、配方及产物位于 `experiments/qwen3_bonus/`。
- 容器编排定义与模块化依赖位于 `deploy/` 与各应用的独立 `compose.yml`。
- 运行时日志、数据与向量索引分别隔离于 `data/`，模型权重隔离于 `models/`，绝对不污染版本库与文档体系。
